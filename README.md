# CS-491

Individual repository for CS 491. Each project lives in its own folder.

| Folder | Project |
| --- | --- |
| [`alljscode/`](alljscode/) | JavaScript basics (`alljscode.js`): types, functions, classes, objects, arrow functions, `map`, `filter`, spread |
| [`vite-react-app/`](vite-react-app/) | Vite + React app with the default starter page replaced by custom content |
| [`react-router-project/`](react-router-project/) | React Router app styled with Bootstrap, with Lottie animations and an added Contact page |

## Running a project

```
node alljscode/alljscode.js

cd vite-react-app        # or react-router-project
npm install
npm run dev
```
